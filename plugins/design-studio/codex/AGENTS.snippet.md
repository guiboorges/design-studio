## Design work (design-studio)

For any design request (creating, changing, choosing, or reviewing a logo, brand, app or web UI, landing page, design
system, typography, colors, layout, social post, ad, poster, magazine, billboard, packaging, image direction, UI copy,
or a critique), invoke the `$creative-director` skill first. It routes the work to the design-studio knowledge skills
(`$typography`, `$color`, `$layout-composition`, `$accessibility`, `$media-specs`, `$visual-styles`, `$design-history`,
`$cognitive-psychology`) and to the design-studio custom agents. These skills hold verified, dated, cited specs that
often differ from model memory: prefer them over recall. Skip this for non-design tasks.

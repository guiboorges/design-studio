# Expressive web research (2026-10)

Evidence behind `plugins/design-studio/skills/expressive-web/`.

- `field-notes.md`: raw notes from 13 Awwwards Sites of the Day opened in Chrome on 2026-10-27 (1512×799, DPR 2): per-site stack probe (libraries, canvases, fonts, colors, fixed layers, clip-paths, split-text spans, computed easings and durations, reduced-motion / view-transition / scroll-timeline CSS), step-scroll observations, hover and click tests, and the cross-site counts. Screenshots were kept out of the repo (size and copyright).
- `verified-facts.md`: library and browser facts (GSAP license and SplitText, gsap.matchMedia, Lenis, Three.js, View Transitions, scroll-driven animations, Barba/Swup/Taxi, Motion, Core Web Vitals, LoAF, `linear()`/`@property`, Howler and autoplay), each with primary sources, verified 2026-10-27.

The probe and step-scroll scripts are reproduced in `build-and-qa.md` §6. These are snapshots: award winners change daily and library versions monthly. Re-check before relying on them after 2027-04.
